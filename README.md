# Permakill

A fast-paced, chaotic twin-stick arcade shooter where death is inevitable — but progress is permanent.

## 🎮 What is this?

**Permakill** is a personal clone/remake of:

- **[KILL - DIE - DO IT ALL AGAIN](https://sirmilkman.itch.io/o)** — the frantic score-based shooter that inspired the core loop
- **Asteroids** — in spirit, with tight arcade combat, movement, and swarming chaos

This game was built from scratch in Python using Pygame in **2 days**, as a personal challenge and milestone to finally finish a game.


## 📦 How to Run

1. Download `game.exe` and `game.assets`
2. Place them in the same folder
3. Launch `game.exe`
